# game-dev-3d

Engine → language: Unity=C#, Unreal=C++/Blueprints, Godot=GDScript/C#, Roblox=Luau,
Love2D/Defold=Lua.

3D formats: OBJ (static, simple), FBX (rigging+anim, industry), glTF/GLB (web/AR,
modern runtime), USD/USDZ (film pipelines, Apple AR), STL/PLY (3D print/scan),
BLEND (Blender native — export before use elsewhere).
Pick: web/AR→glTF · animation→FBX/glTF · print→STL · editing→BLEND.
