# frontend-polish

Kill the tells: no purple/violet gradients, no default-Inter-only, no identical
rounded cards with one grey shadow, no 01/02/03 markers, no tracked-caps eyebrows,
no → on every button.
Add depth: liquid-glass chrome (`backdrop-filter:blur` + translucent + thin light
border + soft shadow) on floating surfaces only; layered elevation; one deliberate
motion moment; springy hover/press (scale, not opacity); subtle grain on flats.
Pick a palette from the subject, 1–2 real typefaces. Real copy, real empty states.
