# ui-design

Design before code: lay out screens as artboards, define the grid, spacing scale,
type scale, and color tokens first. Establish hierarchy (one primary action per
screen), states (empty/loading/error/success), and responsive behavior (stack at
phone width, ≥16px gutters). Then implement against those tokens so the build
matches the design. Pair with frontend-polish for finish.
